# 墨构 MOKO

**自由构想，认真成形。**

一个面向中文创作者的本地优先设计编辑器。使用原生 HTML、CSS 和 JavaScript；无 React、Vue、打包器或运行时第三方依赖。渲染器优先使用 WebGPU，不可用时自动使用 Canvas 2D。

这是一份可运行的编辑器基础版，不是只展示界面的静态稿，也不是与 Figma 功能完全等价的生产级替代品。

## 在线使用与自动发布

GitHub Pages 地址：<https://killpaint.github.io/moko/>。首次发布成功后可访问。

仓库已配置 `.github/workflows/pages.yml`：推送到 `main` 自动进行 JavaScript 语法检查、生成离线单文件并发布；Pull Request 只进行检查与构建，不发布。也支持 Actions 页手动运行。

第一次使用，请在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。工作流使用仓库自动提供的 `GITHUB_TOKEN`，不需要额外填写个人访问令牌。私有仓库使用 Pages 需要支持该功能的 GitHub 套餐；仓库私有不代表发布网站私有。仓库可见性不会被工作流修改。

站点只发布构建后的应用页面，不会把本地服务脚本、测试记录或整个仓库根目录发布为网站。采用单文件输出，可直接部署到 `/moko/` 项目子路径。

## 立即打开

运行 `node build.mjs` 生成 `moko-standalone.html`，再用桌面浏览器打开。代码、图标和示例都已内嵌，不需要联网下载资源。

若浏览器限制本地文件的 WebGPU 或存储，推荐从 localhost 打开：

```bash
cd moko
node server.mjs
```

浏览器访问 `http://localhost:4173`。需要电脑已有 Node.js 18 或更高版本，不需要 `npm install`。服务仅监听本机回环地址，不提供云端服务。

更新源码后重新生成单文件版：

```bash
node build.mjs
```

应用面向桌面编辑。窄屏保留画布、工具栏和导出，隐藏左右面板；手机端不是完整编辑体验。

## 首屏不是图片

内置「山野 · 户外生活」包含：

- 两张手机界面：探索首页、路线详情，所在页面共 161 个可编辑图层。
- 一张设计规范页，包含色彩、字体和按钮组件。
- 山峰、雪顶、河流、图标、文字、导航和卡片均为文档中的真实图层。
- 点击首页推荐卡片的演示热区可进入详情，详情返回按钮可回到首页。

`山野-示例.moko` 是同一示例的可独立导入项目文件。

## 本地保存与隐私

没有登录、遥测、云上传或第三方网络请求。正常可用的浏览器环境下，项目自动保存到当前来源的 IndexedDB，本地工作空间可再次打开不同文件。

请注意：

- 不同域名、端口、浏览器配置及本地文件来源可能使用不同的存储空间。
- 隐私模式、企业策略、存储配额或清除浏览器数据都会影响保存。
- 存储被拒绝时，应用会明确显示「临时编辑 · 请导出备份」，不会假装保存成功。
- 重要文件必须导出 .moko 备份；自动保存不是云备份或可靠性承诺。
- SVG 引用系统字体，接收方字体不同时文字外观可能不同。精确视觉交付使用 PNG。
- 项目导入限制为 60 MB、100 个页面、30,000 个图层、40 级图层嵌套。图片选择限制为单张 20 MB。

## WebGPU 实现

WebGPU 不是一个界面上的标签。`renderer.js` 实际申请 GPUAdapter/GPUDevice，编译 WGSL、创建 render pipelines，使用 storage buffers 与实例化 draw 绘制。

- 矩形/圆角/椭圆：GPU 距离场着色器。
- 文本、贝塞尔路径、图片与阴影：Canvas 排版或光栅化，缓存到多页纹理图集，由 WebGPU 合成。
- 视口裁剪、祖先裁剪、透明度与渐变在相应绘制阶段处理。
- 选择框、锚点、辅助线由独立的 2D 覆盖层绘制。
- 按需请求动画帧，不空转刷新；场景平移不会重新排版未更改的文字。
- 初始化失败、GPU 设备丢失或捕获到 GPU 验证错误时，显示真实的 Canvas 2D 状态。
- 地址后加 `?canvas=1` 可强制使用兼容模式。

WebGPU 需要支持该 API 的浏览器和合适的安全上下文；实际可用性也取决于系统、适配器与驱动。建议使用 localhost 或 HTTPS。

**WebGPU 的实际 GPU 执行、GPU 硬件性能，以及 IndexedDB 的跨刷新持久化，没有在本次环境中完成验证。** 不应把 Canvas 2D 的测试通过描述为 GPU 跑分或完整端到端验收。

## 不包含的能力

不读取 Figma 的 .fig 文件；没有多人实时协作、在线共享权限、布尔运算、矢量网络、组件变体系统、完整混合模式、多个填充与描边、复杂文字混排、OpenType 特性控制、文字转轮廓、约束布局的完整 Figma 语义、自动布局换行、原型智能动画、插件市场或版本分支。

组对象的缩放会按比例处理子层，旋转对象的多选缩放和复杂嵌套约束不等价于成熟设计工具的全部语义。高倍率下文字/路径纹理受到缓存分辨率与图集容量限制，不应称为无限分辨率矢量渲染。没有跨设备、跨浏览器的完整兼容性测试。
